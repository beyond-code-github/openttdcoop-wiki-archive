    Public Server Game 80
    Game Date: 22.01.07 - 30.01.08
    Usual suspects: Floffe, XeryusTC, Mark, ODM, RMJ, rada, jortuny, DJNekkid, tneo, Rob, Adm.Spock, hylje, Shader, thomashauk, BigBoss, Kolo, tneo (extend)
    Gametype: Cargo and Pax
    Trainlength: 5 tiles for cargo and 6 tiles for pax
    Mapsize: 256x512 Temperate
    Version used: r11947 + #openttdcoop-GRF-Pack
    Remarks: This game started out with a chaos-style cargo network, and a separate maglev pax net, with just one condition: all cities connected to a central backbone. Later the cargo part was fixed up to a more regular type, with a separate outer maglev ring for goods.
    A huge SLH by ODM with SLs going both ways, and the pax backbone showing too

    Public Server Game 79
    Game Date: 13.01.07 - 22.01.08
    Usual suspects: DJNekkid, Floffe, Mark, tneo, SmatZ, Osai, Shader, Thraxian, ODM, pm (extend)
    Gametype: Cargo
    Trainlength: 12 on Mainline and 4 tiles on feederline
    Mapsize: 256x1024 Artic
    Version used: r11838 + #openttdcoop-GRF-Pack
    Remarks: The plan chosen asked to use the canal trick that Osai explained on the blog. Connected to this Mainline were four different transfer stations, that each was serviced with a dedicated network for that station. In the North and South drop-off areas were created where all raw materials are transported to. Logic in this was the transfer stations would send the cargo to the furthest drop.
    Showing one of the transfer stations.
    Download: Public Server Game 79 Final / Direct Link to this entry

    Public Server Game 77
    Game Date: 30.12.07 - 06.01.08
    Usual suspects: DJNekkid, Floffe, Mark, tneo, Adm.Spock, Grim4593, Shader (extend)
    Gametype: Cargo using SML
    Trainlength: 6 tiles
    Mapsize: 64x2048
    Version used: r11719 + #openttdcoop-GRF-Pack
    Remarks: The map used was a format never before done, the rectangle shape made it extra challenging to get a nice network in it. Using SML made it fairly easy to get all industries connected without jams.

    Game Date: 14.12.07 - 20.12.07
