    Public Server Game 300
    Game Date: 24.07.15 - 19.08.15
    Usual suspects: dwarf, Hazzard, Jam35, lol, Maraxus, mfb, plonka, sbn, SteveT, Sylf, V435000, Vinnie, YellowMiner (extend)
    Gametype: Mail+Food
    Trainlength: 4 for Mail, Various for food
    Mapsize: 512x512 Arctic
    Version used: r27337 #openttdcoop-GRF-Pack 8.0
    Remarks: For the milestone 300th coop game, we attempted a grand game that demonstrates everything we've learned since PSG 200. The game plan is much like PSG218. The game did not get very grand, but it's a good game to see.
    This one image shows a mature city, local mail networks, the intercity mail network, a farm network, and a food delivery network.

    Public Server Game 295
    Game Date: 17.04.2015-04.05.15
    Usual suspects: Jam35, Maraxus, Sylf, Mark, V453000, Plonka, t4 (extend)
    Gametype: Cargo
    Trainlength: TL2
    Mapsize: 512x512 Arctic
    Version used: r27221 #openttdcoop-GRF-Pack 8.0
    Remarks: An "oldskool" style plan featuring lots of hubs, stations and mainlines. A lot of effort was put into expanding almost the entire network to 4 lanes wide, resulting in a great game with an impressive 2600 trains running smoothly.
