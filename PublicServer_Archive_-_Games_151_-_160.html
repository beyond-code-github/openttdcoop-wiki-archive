    Public Server Game 160
    Game Date: 24.09.09-03.10.09
    Usual suspects: Mark, Petert ^Spike^, V453000, HDIEagle, Franco, jdread, ostannard, Chris Booth, Lord Aro, Welsh, jondisti, DCritic (extend)
    Gametype: Cargo
    Trainlength: TL3
    Mapsize: 512 x 512 Sub-Arctic
    Version used: r17496 #openttdcoop-GRF-Pack 7.3
    Remarks: An organic ML layout was chosen with mainlines that fitted nicely into the valleys and avoided the snowy peaks, which provided some pitoresque spots. The initial connections required some extensive upgrading in the later game and also some mainlines had to be added, once this was done the network ran pretty smoothly.

    Public Server Game 159
    Game Date: 15.09.09-24.09.09
    Usual suspects: FiCE, Petert, DCritic (extend)
    Gametype: Cargo
    Trainlength: TL5 & 10
    Mapsize: 2048 x 256 Temperate
    Version used: r17496 #openttdcoop-GRF-Pack 7.3
    Remarks: Expert industries with stockpile limits were loaded for this game. We had a central ML with terminals connected directly to it. These terminals were connected to local rings which both produced and accepted cargo. ML trains were used to balance supply and demand over the rings.

    Public Server Game 157
    Game Date: 27.08.09-06.09.09
    Usual suspects: Mark, Combuster, Petert, ^Spike^, hylje, Ammler, Franco, Mks, Highpinger, Farden, Chris Booth, Thraxian, (extend)
    Gametype: ICE/S-Bahn
    Trainlength: TL 5
    Mapsize: 256 x 256 Temperate
    Version used: r17288 #openttdcoop-GRF-Pack 7.3
    Remarks: Rather than going with the conventional load-unload orders we chose to have intelligent stations pulling trains of the ML for this game. Each of the 8 stations connected to the small or wide ML respectively pulled 1/4 or 1/8 trains off, making sure pax was distributed equally over the stations. Of course this resulted in some nice overly complex constructions. hacked in mainlines and jamming sidelines, all in the middle of the metropolis covering the entire map. Also have a look at Combuster's blog post about this game.
    One of the major BBHs, BBH 03, rebuilt many times

    Public Server Game 154
    Game Date: 09.08.09-14.08.09
    Usual suspects: Nickman, Tussengas, Fuco, ^Spike^, Mark, Chris Booth, XeryusTC, HDIEagle, FiCE, Barbaar, Petert, andyp, sukasa, insulfrog, Neuroticus, Thraxian (extend)
    Gametype: Cargo + Pax
    Trainlength: TL 15
    Mapsize: 1024 x 1024 Tropical
    Version used: r17170 #openttdcoop-GRF-Pack 7.3
    Remarks: The map was straightforward, flat and thus easy to build big constructions. Goal was to get a total population of > 2.5 Million with only 4 cities. Few succeeded and we almost went bankrupt while trying :). The main network was built with huge capacity which was never reached so no upgrades were needed. We ended up with a population of 1.1 Million, which is about half of the given goal.

    Public Server Game 152
    Game Date: 22.07.09-02.08.09
    Usual suspects: Nickman, HDIEagle, ^Spike^, OwenS, satyap, ODM, Petert, J_Darnley, FiCE, Razaekel, JaW, Hans, planetmaker, Raiscan, skasi (extend)
    Gametype: Gametype:Cargo_Concept
    Trainlength: TL 3
    Mapsize: 1024 x 512 Sub-Tropical
    Version used: r16973 #openttdcoop-GRF-Pack 7.3
    Remarks: The game started out with a very simple plan and structure. Most of the game was straight forward except for the rebuilding of all the hubs when we added the fourth and fifth main line. The factory drop/pickup was rebuilt several times, and multiple exit strategies were used. In the end we used an experimental merging technique which seemed to be able to cope with the large load of trains.
    Huge Factory station which was rebuilt several times, the exit was rebuilt even more with various merging strategies.

    Public Server Game 151
    Game Date: 16.07.09-22.07.09
    Usual suspects: planetmaker, Thraxian, mixrin, Hans, Avdg, Nickman, HDIEagle, ^Spike^, OwenS, Radicalimero , Wall-D, satyap , Combuster (extend)
    Gametype: PAX Semi-Chaos
    Trainlength: TL 10
    Mapsize: 256 x 1024 Temperate
    Version used: 16903 #openttdcoop-GRF-Pack 7.3
    Remarks: A game stationed on a set of Japanese islands, which were quickly filled by tracks. The plan states that the big islands need one Shinkansen station each, with a local network filling it with passengers. In the end, except for a few nature reserves, all islands were covered by track, town, road or station. The game also saw some expertimal order usage, exploring the possibilities of conditional orders.
    Uetani local and Shinkansen station.
