PSG 200 aka PF 2011

1 January 2011, by V453000

It is here! Public Server Game 200 finally begun with the beginning of new year 2011 and the end of 2010. In the last year, we had some amazing games, one better than other. We beaten a lot of our records and set some new milestones to reach. After all that, as an “ultimate game” comes public server game 200, which is meant to be as a collection of all the stuff we did not onlu in the last 12 months, but all that we ever did. For more information what we prepared for you as psg200, read further. 🙂

Have fun and Happy New Year!

Public Server Game 200

When we started thinking about game 200, we had several ideas to go for. We wanted the game to be fun for everybody (which is hard to reach with normal games), to be unique but somehow ultimately related to the rest what we did already.
The idea that followed these requirement best was a game with many islands, dividing the map. Every of such islands should represent some piece of our building style. These pieces weren’t very hard to find, since there aren’t that many things that would be reasonable to be represented. More information about the exact structure in the game.

We are looking forward to see you in the game 200 and once again, Happy New Year!
