OpenTTD 0.6.0 released

1 April 2008, by pm

Now it’s for real: the final version of 0.6.0 has already been released late yesterday and it looks like it isn’t an April’s fools joke.

Go and get it from sourceforge, enjoy and thank the people behind this for another milestone in the OpenTTD development.

With respect to the previous stable release a lot of new features have been added like

  • newhouses
  • newindustries
  • signals and diagonal tracks under bridges
  • trams
  • autoslope
  • one-way roads
  • half tile slopes
  • drive through road stops
  • group management of vehicles

Compared to the release candidate only very few bugfixes were needed:
- Fix: Final formatting of some string codes from NewGRFs was not done correctly [FS#1889] (r12488)
- Fix: Timetable times for aircraft were always doubled [FS#1883] (r12477)
- Fix: Remove broken endian-dependent code and unnecessary rgb to bgr swapping [FS#1880] (r12453)
- Fix: Do not 'disable' the drawing of autorail overlays when the tile is 'error'-marked (red pulsating selection) [FS#1871] (r12439)
- Fix: Plural rule for Icelandic was wrong (r12417)
