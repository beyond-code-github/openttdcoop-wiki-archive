    Public Server Game 49
    Game Date: 11.07.07 - 14.07.07
    Usual suspects: Ammler, LoneR, Phazorx, thgergo, Gamer, SpaceCom, Addi, Kolo, Osai, De_Ghost, Mark, Nitehawk, XeryusTC, strstrep (extend)
    Gametype: ICE/SBahn with Maglev/Rail
    Trainlength: 10 tiles
    Mapsize: 512x512
    Version used: r10532 +#openttdcoop-GRF-Set w. DBSetXL
    Remarks: The Idea: a plain map, five cities, create a local/express traffic network and grow the towns as big as possible. We stopped the game after reaching 1,700,000 citizens because it would have taken too long to grow the cities so big to cover the whole map. Anyway the game is continued as an RBC-Game.
    Map Overview.

    Public Server Game 48
    Game Date: 09.07.07 - 11.07.07
    Usual suspects: Andy, Mark, Adm.Spock, Nitehawk, Henry, Lone, strstrep, Rejdukien, Altaree, De_Ghost, Gamer (extend)
    Gametype: Chaos Theorie with Rail
    Trainlength: 8 tiles
    Mapsize: 512x1024
    Version used: r10532 +#openttdcoop-GRF-Set w. CanadianSet
    Remarks: A Fast Chaos Game with PAX, Quick and easy, De_Ghost needed too make the biggest city again and Gamer created a Aircraft network. Really chaotic. Lot's of nice hubs and stations
    The town area of Hanford is really nice. Two Terminus Station's for Passengers and a Mainline straight through the City.

    Public Server Game 47
    Game Date: 16.06.07 - ??
    Usual suspects: Gamer, Red, XerusTC, De_Ghost, Sedontane, Bilbo, LittleMikey, Nexus, strstrep (extend)
    Gametype: Cargo Concept with Rail
    Trainlength: 8 tiles
    Mapsize: 512x512
    Version used: r10438 +#openttdcoop-GRF-Set w. DBSetXL
    Remarks: A large Game with 8 Tile trains, got some new people playing but game went fine. Could use much more improvement. We didn't reach 500 Trains on the map. While the northern mainline is full of trains, the southern ones are empty.
    BBH 02, the most heavily-used backbone hub.

    Public Server Game 45
    Game Date: 11.06.07 - 16.06.07
    Usual suspects: hylje, Oxygene, Dark_Link, De_Ghost, Turilas, strstrep, LittleMikey, skol, Teddy, Roujin (extend)
    Gametype: TGV_Concept with MonoRail
    Trainlength: 2 tiles
    Mapsize: 256x256
    Version used: r10295 + #openttdcoop-GRF-Set
    Remarks: In this game we had TTT and transported Pax to two big Central Stations. We didn't build any SBahn. Instead we transported Pax from telescope stations in all Cities directly to the major ones. In the middle hylje built a big BBH which isn't truly four-way but like looks like this: <:> (no need for: #).

    Public Server Game 44
    Game Date: 08.06.07 - 11.06.07
    Usual suspects: OwenS, XeryusTC, Dark_Link, Phazorx, strstrep, Osai, Addi, DeGhost, Nickman, Oxygene, LittleMikey (extend)
    Gametype: Cargo with MagLev
    Trainlength: 7 tiles
    Mapsize: 2048x128
    Version used: r10067 + #openttdcoop-GRF-Set
    Remarks: A nice game which made use of the new Shift_Mainlines (SML) and some big station areas at the north and south ends of the map. Unluckily you need a very huge amount of trains to bring our game concept in trouble on a three-track mainline.
    Osai's grand south station taking a beating... try to count all the trains :o)

    Public Server Game 43
    Game Date: 03.06.07 - 08.06.07
    Usual suspects: OwenS, hylje, S_m_w, Phazorx, Kejhic, Osai, Teddy, strstrep, Sionide, Nickman (extend)
    Gametype: ICE+SBahn with Norwegian Trainset
    Trainlength: Express: 6 tiles & Local:~3-5 tiles
    Mapsize: 512x512
    Version used: r10048 + #openttdcoop-GRF-Set
    Remarks: This game is quite similar to PSG#42, but now we used the great new feature of trams in OpenTTD. Basically we missed the aim to cover the whole map with city area, but anyway this is an awesome game.
    Largest city in game, was grown by S_m_w mostly and had several re-do's on station and S-bahn rings... However we still failed to move passengers fast enough.

    Public Server Game 42
    Game Date: 31.05.07 - 03.06.07
    Usual suspects: OwenS, hylje, S_m_w, TheJosh, Dark_Link, Phazorx, Addi, XeryusTC, IOO, de_ghost, Kejhic, Osai (extend)
    Gametype: ICE+SBahn with American Trainset
    Trainlength: Express: 8 tiles & Local:~3-5 tiles
    Mapsize: 512x512
    Version used: r10029 + #openttdcoop-GRF-Set
    Remarks: In this game we built very big cities with nice local and express traffic. The game was just before the up-and-coming trams
    Senwood with 100,000 inhabitants. The city was mainly developed by de_ghost. In the north-east you can see the MainStation transporting ~10k pax per month.

    Public Server Game 41
    Game Date: 14.05.07 - 31.05.07
    Usual suspects: Kul, Doke, Dark_Link, TheJosh, Tino, Gamer, Ammler (extend)
    Gametype: Cargo + MarsSet
    Trainlength: 5 tile trains
    Mapsize: 256x1024
    Version used: r9910 + #openttdcoop-GRF-Set
    Remarks: This was the first game with the MarsSet (a toyland replacement grf). It shows the variety and complexity of the openttdcoop newgrf-package. A lot of people don't like the toyland grfs and neither the marsland ones. But I think it was quite funny to play such a scenario.
    A nice concept for a SLH by Doke.
