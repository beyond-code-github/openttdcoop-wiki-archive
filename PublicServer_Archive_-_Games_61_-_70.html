    Public Server Game 70
    Game Date: 19.11.07 - 24.11.07
    Usual suspects: Floffe, SmatZ, LittleMikey (extend)
    Gametype: Cargo
    Trainlength: 2 tiles
    Mapsize: 256x256
    Version used: 0.6.0-beta1 + #openttdcoop-GRF-Set 6 beta
    Remarks: A pretty crowded game due to the Tilelength of 2 and the very small map. We had to completly rebuild the ML because the ML could not handle the amount of trains.
    The South of the Map

    Public Server Game 69
    Game Date: 12.11.07 - 18.11.07
    Usual suspects: Phazorx, Franco, Thraxian, AntB, Kommer, Mark, Kul, LittleMikey, Shader, SmatZ, tneo, Floffe, Levi, eJoJ (extend)
    Gametype: Maglev Pax with UKRS
    Trainlength: 3/6 tiles
    Mapsize: 512x512
    Version used: r11369 + #openttdcoop-GRF-Set 6 beta
    Remarks: Unfortunataly, this map was a bit small for the network design we chose. The network was quite good IMO, but was really suited for a map bigger then what we had. Also, the layout of the map was not very good, with only two towns lying in the north-east part of the map, effectivly making anything we built there useless.
    The NE Terminal with transfer station.
    Download: Public Server Game 69 Final / Direct Link to this entry


    Public Server Game 68
    Game Date: 21.10.07 - 12.11.07
    Usual suspects: Phazorx, Franco, Thraxian, AntB, Kommer, Mark, Kul, LittleMikey, Shader, SmatZ, Floffe (extend)
    Gametype: Cargo
    Trainlength: 5 tiles
    Mapsize: 512x512
    Version used: r11369 + #openttdcoop-GRF-Set 6 beta
    Remarks: We pushed this network to the limits. There was a huge MSLH in the middle of the map but it never got used to its full potential because the rest of the network could not cope with that many trains.
    The MSLH sitting in the middle of the map.

    Public Server Game 67
    Game Date: 7.10.07 - 21.10.07
    Usual suspects: Phazorx, Franco, Thraxian, AntB, LittleMikey, Shader, Night-Eagle (extend)
    Gametype: Cargo
    Trainlength: 5 tiles
    Mapsize: 512x512
    Version used: r11235 + #openttdcoop-GRF-Set 6 beta
    Remarks: We made a central transfer area, where all the resources and secondary goods were unloaded, then transported to several small drop stations at the edges of the map. This was the first Public Server game with new industries (clay, plastic, fuel oil, etc.)
    One of the Backbone Hubs of the inner circle.

    Public Server Game 66
    Game Date: 29.09.07 - 03.10.07
    Usual suspects: Mark, Godde, N101, AntB, LittleMikey, SmatZ (extend)
    Gametype: Cargo / Chaos / TGV
    Trainlength: 3/5/7 tiles
    Mapsize: 512x512
    Version used: r11152 + #openttdcoop-GRF-Set 6 beta
    Remarks: In this game we supplied desert towns with water and food to make them grow. When the towns started growing we made a chaos-like PAX network between the towns. Also, Freight Train weight was x8 on full loads
    The central Food Proccessing plant, producing ~30.000 units of food every month.
    Download: Public Server Game 66 Final / Direct Link to this entry


    Public Server Game 65
    Game Date: 24.09.07 - 29.09.07
    Usual suspects: Mark, LittleMikey, Kommer, Phazorx, Kolo, Thraxian, skol, Sedontane, grim4593, DeGhost, fr4g, AntB, hylje, B4light (extend)
    Gametype: Cargo
    Trainlength: 7 tiles
    Mapsize: 1024x1024
    Version used: r11152 + #openttdcoop-GRF-Set 6 beta
    Remarks: Chosen Dual SML plan set the limits pretty high and with standard 500 trains network was hardly even used. Following necesary move to more powerfull server (thanks to Ammler for hosting) some parts of the network shown signs of stress after reaching 1500 trains mark. Overall very well developed game, some things still left to conenct but average PC can barely play this with reasonable speed already.
    North west corner of the map, factory drop (a bit left from the center) serviced by more than 500 trains. Goods pickup on far left visited by ~200 trains, making £600,000 per trip. Most of trains are spending 80% of their time moving from and to stations.
    Download: Public Server Game 65 Final / Direct Link to this entry
