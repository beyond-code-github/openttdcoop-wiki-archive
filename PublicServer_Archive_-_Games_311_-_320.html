    Public Server Game 319
    Game Date: 15.10.16 - 12.11.16
    Usual suspects: Jam35, Sylf, Maraxus, Lejving, maqifrnswa, StarLite, Mark, ZXbiohazardZX, lol, britboy3456, Ethereal_Shiver, Levi (extend)
    Gametype: FIRS 'In a Hot Country'
    Trainlength: 5 mono (main) and 3 mglv (supplies)
    Mapsize: 512x512 Tropic
    Version used: r27661 #openttdcoop-GRF-Pack 8.0
    Remarks: The game used an intermediate setting of FIRS 2 'In a Hot Country'. Not too many industries to handle and not too few to be too simple. The voted plan used timed deliveries of farm and engineering supplies to the relevent primaries so as to keep them at maximum production 'Gung-ho' at all times. This was done using an SRNW style network with an unreachable waypoint order for trains, forcing them to leave a main ring where we wanted to drop supplies. This was only a small part of the network with the main network being a more normal style cargo game but very busy with 4 lines in places . The game ended with over 2000 trains.
    Two intertwining networks plus a fair amount of logic track makes some interesting puzzles.
    Download: Public Server Game 319 Final / Direct Link to this entry
    Public Server Game 318
    Game Date: 10.09.16 - 15.10.16
    Usual suspects: Sylf, Maraxus, Jam35, V45300, Lejving, maqifrnswa, Arveen, lol (extend)
    Gametype: Cargo Refit
    Trainlength: 3 Monorail
    Mapsize: 512x512 Arctic
    Version used: r27595 #openttdcoop-GRF-Pack 8.0
    Remarks: A classic style refit game with trains dropping back cargo if it wasn't more than 80% full. That way empty trains don't waste a journey. The game started LL_RR but in the end got 7 lines in places and over 2000 trains. Some interesting SRNW sidelines were also in place here with different methods of train control.
    A BBH MSH SLH and SL.

    Public Server Game 314
    Game Date: 04.05.16 - 03.06.16
    Usual suspects: Mark, Dwarf, Jam35, lol, Sietse, BiG_MEECH, Absolutis, barnex, bubbleheads, Maraxus, NCommander, Tray, tyteen4a03, be8f07c4 (extend)
    Gametype: YETI cargo (tired yeti mode)
    Trainlength: 3 "Get Heavy"
    Mapsize: 512x512 Tropic
    Version used: r27534 #openttdcoop-GRF-Pack 8.0
    Remarks: The game was a test of the new YETI release. A new mode using tired Yeti that need to return to Yeti yards was used. Instead of doing things simply though, we chose to refit trains everywhere giving us a few groups of trains with many orders. With no trains running empty we achieved huge amounts of delivered cargo for the number of trains.

    End game train count was 2100 with no jams, most of the network was upgraded to 4 lines and 3 YETI yards were running near maximum production.

    One of the Yeti yard stations and hub.

    Public Server Game 313
    Game Date: 20.04.16 - 04.05.16
    Usual suspects: Jam35, Clockworker, Ramsvs, lol, Absolutis, damalix, tyteen4a03, Mark, bubbleheads, DyeH, Sietse, Maraxus, NCommander, Ben_ (extend)
    Gametype: Cargo
    Trainlength: 5
    Mapsize: 512x1024 Arctic
    Version used: r27534 #openttdcoop-GRF-Pack 8.0
    Remarks: FIRS Arctic Basic industries was loaded on a large, mountainous and very watery map. Having no fixed plan resulted in an extensive LR network, about of half of which got expanded to LL_RR later on in the game. Primary industries were set not to increase production, and we kept the number of primaries connected balanced, which resulted in very even traffic flows. In the end of the game, almost 1100 trains fully serviced all industries; no cargo waiting at stations.
    Yet another one of Mark's eyecandies.
