    This is the game archive of our Public Server. All games are listed with screenshots, game information and a final savegame.

    Please note: Many savegames require a certain version of OpenTTD to run since OpenTTD is not fully backward-compatible. Most games were played with a OpenTTD Nightly Version. Get the nightly at http://www.openttd.org/en/download-nightly. Starting with Public Server Game 8, #openttdcoop introduced a set of additional GRFs.
