    Public Server Game 40
    Game Date: 06.05.07 - 25.06.07
    Usual suspects: Phazorx, Dark_Link, thgergo, Kolo, alanin, Osai, hylje, XeryusTC, eJoJ, WhySheepKill, SwordFish, JameiLei, Tino, Mucht, Cipri, Zr40, Kul, handi, Adm.Spock, Schlauke, altaree (extend)
    Gametype: Alpine Climate + UKRS
    Trainlength: 4 tile trains
    Mapsize: 512x512
    Version used: r9796-r10170 + #openttdcoop-GRF-Set
    Remarks: The game was very slow at start due to unorthodox and complex mainline design. Eventualy most structure was in place, and we learne that server capacity is much lower than network can handle. 500 trains were handled moving quite fast with no major issues. Osai has started quest for alternative server to continue the game, and thanks to Alanin we got one! Game has grown nearly to 1000 trains (however network capacity was closer to 850, past that amout of trains hiccups bacame quite often).
    [image unavailable]
    One of farm group terminals, producing about 7500 units of combined cargo per month served by more tha 80 trains.

    Public Server Game 37
    Game Date: 19.04.07 - 28.04.07
    Usual suspects: Phazorx, STE1N, Addi, hylje, EoD, welterde, XeryusTC, Adm.Spock, Osai, HMage, eJoJ, Edik, TinoM (extend)
    Gametype: Temperate Climate
    Trainlength: 12-Tile Trains for Raw-Materials and 20-Tile Trains for Goods
    Mapsize: 1024x256
    Version used: r9712 + #openttdcoop-GRF-Set
    Remarks: The trains are very long. The network idea was to have express-sideline and local-tracks. But somehow those local tracks were not as successful as proposed. There were no balancing and prios between SL and local, what means in fact no network optimisation.

    Public Server Game 36
    Game Date: 13.04.07 - 19.04.07
    Usual suspects: Cipri, Phazorx, STE1N, Addi, Kejhic, hylje, EoD, UnderBuilder, SwordFish, hdp, welterde, Ammler, XeryusTC, Adm.Spock, Osai, Teddy (extend)
    Gametype: Sub-tropical Climate, TTRS
    Trainlength: 6-Tile Trains, Cargo + Pax. between Main-Cities
    Mapsize: 512x512
    Version used: r9712 + #openttdcoop-GRF-Set
    Remarks: A nice network idea. Two main cities we served with all the things to grow. Later on we transported also there Passengers and Mail. A lot of new players joined openttdcoop while running this game. It shows how fast you can learn to build proper junctions.

    One of the main stations, its eye-candy with those dead-tracks included into the look and feel.

    Public Server Game 35
    Game Date: 06.04.07 - 13.04.07
    Usual suspects: AdmSpock, Ammler, Addi, Cipri, hylje, Progman, Osai, JameiLei, welterde, XeryusTC (extend)
    Gametype: Temperate Climate, DBset, Oil+Coal+Wood+Goods
    Trainlength: 8-Tiles for Cargo, 16 tile maglevs for Goods
    Mapsize: 1024x1024, 500 train limit
    Version used: r9570 + #openttdcoop-GRF-Set
    Remarks: As we were limited to only 500 trains, we turned this into a long train game, with only a few cargoes transported. The networkwas based on an X-shaped pair of ML's, with multiple SL's per leg. We saved the inner track for the goodstrains, and converted those to maglevs as soon as we could. Another game with lots of fun with the newgrfs
    [image unavailable]
    Luckily, the BBH became a lot clearer once we switched one track to maglev.
