    Public Server Game 260
    Game Date: 30.05.2013 - 11.06.2013
    Usual suspects: V453000, Vinnie, mfb, Sylf, planetmaker, Mazur, Mark, Thraxian, zxbiohazardzx, nicfer, Maraxus, Absolutis, perk11, Ryton, Jam35, Abacus, RT78900, Abacus, scshunt (extend)
    Gametype: Cargo
    Trainlength: TL3
    Mapsize: 512 x 512 Temperate
    Version used: r25385 #openttdcoop-GRF-Pack 8.0
    Remarks: This game started as a normal cargo game with 1 drop per cargotype and a single huge goods drop in center. With increasing traffic on mostly wood the network quickly evolved into a set of huge set of linked BBH and MSH. It provided some good learning experience for new players, and V453000 used some stations in this game to explain overflows & priorities for overflow-releases a bit more detailed.
    Picture can be found above here.

    Public Server Game 259
    Game Date: 9.05.2013 - 29.05.2013
    Usual suspects: Sylf, mfb, V453000, nicfer, Vinnie,, Mazur Jam35, bio, Maraxus, Absolutis, Fulsalin, Miolin, Kosmic, perk11, Pocok, Ryton, Tycoondemon (extend)
    Gametype: Cargo
    Trainlength: TL5
    Mapsize: 512 x 512 Tropic
    Version used: r25267 #openttdcoop-GRF-Pack 8.0
    Remarks: This game we made a single BBH in the middle and it connected to the three main drops on the edges of the map. In these maindrops every train that produced secondary cargo will refit to that cargo and load it. The secondary cargo is unloaded at every SLH and refit back to the primary. We extended the complete mainline to 4 tracks and even 5 tracks on some points. The mad thing we did this game is use an underpowered train. Every time the train was full and went up a slope it would slow down. This created some nice mergers that use gravity and we tried our best to prevent slopes on a mainline. Also notice that the lack of a lot of mainline will give fewer SLH's that in turn will have lots of industries connected. Every SLH has 2 lines in and out of the sideline.
    The central BBH has quite some traffic. It also grew a little in the needed expansions.

    Public Server Game 257
    Game Date: 1.04.2013 - 13.04.2013
    Usual suspects: bio, Darigaaz, dwarf, G-Tus, Jam35, mfb, molv, Sylf, uliko, Vinnie, V453000 (extend)
    Gametype: Cargo and Pax, multiple systems
    Trainlength: TL2,3,4,5,6,7,10
    Mapsize: 512 x 1024 Temperate
    Version used: r25137 #openttdcoop-GRF-Pack 8.0
    Remarks: A year ago, we celebrated the initial release of NUTS with PSG 231. We celebrated 1st anniversary of NUTS using the similar game plan as 231 - representing all different classes of trains, everything from the slowest cargo trains to the fastest passenger monorails and maglevs. And everything in between.
    Maglevs. Rails. Monorails. Wetrails. They're all represented in this game.

    Public Server Game 256
    Game Date: 11.03.2013 - 31.03.2013
    Usual suspects: G-Tus, Absolutis, Big Meech, Biohazard, Dom, dwarf, Jam35, Killian, LoPo, Maraxus, Mark, mfb, ODM, ondo, Sylf, Troy McClure, V453000, XeryusTC (extend)
    Gametype: Cargo
    Trainlength: TL5
    Mapsize: 512 x 512 Tropic
    Version used: r25071 #openttdcoop-GRF-Pack 8.0
    Remarks: Four-way backbone hubs. That is what defined this game. We started the game with a pseudo Martian scenario, inspired by Martian town names. Throw-in a hippy theme game plan. Throw in a plan involving five four-way BBHs. Throw in a plan involving two separate networks - primary and secondary cargo lines. What you get is a massive fun!
    Slugs and Brainmelters. That's an awesome combo for the Martian environment.

    Public Server Game 255
    Game Date: 24.02.2013 - 11.03.2013
    Usual suspects: V453000, mfb, dwarf, Sylf, Dom, LoPo, Big_Meech, Jam35, Biohazard, Maraxus, Absolutis, G-Tus (extend)
    Gametype: Cargo
    Trainlength: TL3
    Mapsize: 512 x 512 Arctic
    Version used: r25071 #openttdcoop-GRF-Pack 8.0
    Remarks: This game featured an cargo refit plan. There were two unique aspects to this game. First, each side lines had their own Printing Works. Second, each side lines had their own food and oil goods drop. Lopo made a unique sideline of his own, featuring SRNW refit plan (SLH06). We finished the game after spamming the map with about 1200 trains.
    We built all of the mainlines above the snow line.

    Public Server Game 254
    Game Date: 14.02.2013 - 24.02.2013
    Usual suspects: Sylf, V453000, mfb, dwarf, Dom, LoPo, Big_Meech, Jam35, Biohazard, pietballas, Kyler, Maraxus, Firestar (extend)
    Gametype: Cargo
    Trainlength: TL5
    Mapsize: 512 x 512 Temperate
    Version used: r25034 #openttdcoop-GRF-Pack 8.0
    Remarks: After a few unique style games we've been playing lately, we went back to the classic coop style cargo game with 5-tile long maglev trains. The plan featured two rings--north and south--connected by a big ML. We finished the game with 890 trains filling the map.
    The connector in the middle was virtually a four-way hub, used by most of the trains on the map.

    Public Server Game 253
    Game Date: 13.01.2013 - 14.02.2013
    Usual suspects: V453000, Mark, mfb, Ryton, Kalaidos, Dilandau, Iklucas, Tray, Vovolov, Sylf (extend)
    Gametype: Pax
    Trainlength: TL5
    Mapsize: 512 x 512 Arctic
    Version used: r24990 #openttdcoop-GRF-Pack 8.0
    Remarks: We started with a new type of SRNW pax plan: each town is to have its own group of SRNW trains. This plan was not followed closely, and fell apart as the game progressed. We switched our plan, and created a unreacheable waypoint style of SRNW ring just like we did in PSG 207. Players' interest in this game became extremely low, so this game was left incomplete.
    Nuttown was one of three cities on the map that featured one long road covering the entire city..
