    Public Server Game 289
    Game Date: 9.11.2014-22.11.2014
    Usual suspects: Sylf, o11c, damalix, V435000, Jam35, Hazzard, Maraxus, britboy3456, ChingMeiLee, Vinnie, StarLite, Djanxy (extend)
    Gametype: PAX
    Trainlength: TL5
    Mapsize: 512 x 512 Sub-Arctic
    Version used: r27018#openttdcoop-GRF-Pack 8.0
    Remarks: This was supposed to be a quick passenger game to kill some time until the release of the next version of YETI, which we will use in PSG 290. The game plan had two 1-way loops, both running in the same direction, connected at 4 locations. If you thought this sounds like a very innocent plan, wait until you look at the game save. This is the power of coop game style - we can make any simple game plan into a big fun.

    Public Server Game 286
    Game Date: 15.9.2014-26.9.2014
    Usual suspects: Jam35, Sylf, Hazzard, V453000, bio, Maraxus, Djanxy, BallC, John, scshunt, o11c, Saladan0 (extend)
    Gametype: Cargo
    Trainlength: TL3 & TL6
    Mapsize: 512 x 256 Sub-Arctic
    Version used: r26830#openttdcoop-GRF-Pack 8.0
    Remarks: We started with a map with 8 large islands. Using this landscape, we built two separate networks. One is on the land, running TL3 trains, connecting the islands with bridges. Second network was built with wet trains, built on the water, running TL6 boat trains. With a mountainous nature of this map, it became difficult to expand quickly, so we ended the game quickly too. We still ended the game with nearly 1100 running trains.
    [image unavailable]
    Combined view of BBH 01 and BBH03. After massive upgrades made by players, these hubs look quite impressive compared to their original constructions.

    Public Server Game 285
    Game Date: 30.8.2014-15.9.2014
    Usual suspects: Sylf, Jam35, Hazzard, bio, Maraxus, Djanxy, BallC, John, Chaz, scshunt, verm (extend)
    Gametype: Cargo
    Trainlength: TL4
    Mapsize: 512 x 256 Sub-Tropic
    Version used: r26720#openttdcoop-GRF-Pack 8.0
    Remarks: This was a classic cargo game. Simple network plan with innocent starting point of LL_RR mainlines. What was not so innocent is the players' willingness to stretch the coop style playing. When we finished the game, almost all of the mainlines were upgraded to LLL_RRR, supporting about 1050 trains. This was a quite fun game.

    Public Server Game 284
    Game Date: 6.8.2014-30.8.2014
    Usual suspects: V453000, Jam35, Sylf, Hazzard, bio, Maraxus, Generalcamo, avdg, mfb, Vinnie, Sassafrass (extend)
    Gametype: Cargo (YETI)
    Trainlength: TL14
    Mapsize: 512 x 512 Toyland
    Version used: r26720#openttdcoop-GRF-Pack 8.0
    Remarks: This game was played on toyland map, but that wasn't the point of this game. This was a YETI game, with refit, and with 14 tile long trains! Combine that with starting ML of LLL_RRR, we had some monster hubs from the start of the game. Those monster hubs made it difficult to upgrade the MLs, but there still were some nice stuff to look at on this map.

    Public Server Game 283
    Game Date: 29.7.2014-6.8.2014
    Usual suspects: V453000, Jam35, Sylf, Hazzard, bio, nicfer, Maraxus, Syl59, Abacus, Generalcamo, LoPo, XeryusTC (extend)
    Gametype: Pax
    Trainlength: TL10
    Mapsize: 512 x 512 Temperate
    Version used: r26720#openttdcoop-GRF-Pack 8.0
    Remarks: We started this game, wanting to test the NUTS monorail intercity trains that got new stats recently. Having only 4 main stations on the map, SBahns for all those files grew quite large. We have some nice looking towns on this map. In the end, we learned that the new monorail intercities are too powerful compared to the rest of the trains in the set.
