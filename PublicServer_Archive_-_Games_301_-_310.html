    Public Server Game 309
    Game Date: 13.01.16 - 24.01.16
    Usual suspects: Mark, Mazur, Jam35, V453000, Maraxus, lol, Ramsvs, Sylf, Clockworker, solitaire (extend)
    Gametype: ICE/S-Bahn (Mail)
    Trainlength: 5 / Various
    Mapsize: 512x256 Temperate
    Version used: r27452 #openttdcoop-GRF-Pack 8.0
    Remarks: Possibly our best pax game to date. We chose to use mail rather than pax, which made for a much more balanced game. Most towns are serviced at least 60% and almost all mail is moved across the map. Towards the end of the game the LLL_RRR backbone filled up nicely and the map is almost entirely covered in towns. Featuring lots of nice towns with organic transfer networks and loads of details. Great game.
    Mark's port and ICE, one of the highlights of the game.
    Download: Public Server Game 309 Final / Direct Link to this entry

    Public Server Game 307
    Game Date: 21.11.15 - 07.12.15
    Usual suspects: Mark, Mazur, cha0tics, Jam35, barnex, lol, Ramsvs, Sylf (extend)
    Gametype: Cargo
    Trainlength: 3 (Primary) 9 (Secondary)
    Mapsize: 512x128 Toyland
    Version used: r27452 #openttdcoop-GRF-Pack 8.0
    Remarks: A quick game with an interesting concept: mixed train lengths on same network. Long trains had a simple looping route and were always given priority which allowed us to merge the shorter trains only, saving space and complexity.
    Drop station and 2 pick stations at south end of network.
    Download: Public Server Game 307 Final / Direct Link to this entry
    Public Server Game 306
    Game Date: 03.11.15 - 21.11.15
    Usual suspects: Jam35, lol, cha0tics, dwarf, Sylf (extend)
    Gametype: PAX
    Trainlength: 7
    Mapsize: 512x512 Temperate
    Version used: r27428 #openttdcoop-GRF-Pack 8.0
    Remarks: An orderless SRNW PAX game where mainline trains were controlled 100% by logic gates. Shows some inventive logic constructions, game ended with 700 mainline trains and extensive SBahn systems.
    One of the BBH's that was upgraded to 3 lines, includes a logic controlled split and a new type of slowdown-avoiding merge.
    Download: Public Server Game 306 Final / Direct Link to this entry
    Public Server Game 305
    Game Date: 18.10.15 - 03.11.15
    Usual suspects: Sylf, dwarf, Jam35, cha0tics, Maraxus, Mazur, Mark, lol (extend)
    Gametype: YETI Cargo
    Trainlength: 3 Maglev 'Get Heavy'
    Mapsize: 512x512 Temperate
    Version used: r27387 #openttdcoop-GRF-Pack 8.0
    Remarks: The plan was to use a single YETI yard to support the whole network. After some work and number-crunching, an optimal number of trains for each chain was found to keep the YETI town growing. Unfortunately we maxed out the number of YETIs that could be produced so the game ended prematurely. Still the network had grown to at least 3L 3R everywhere and ended with over 1500 trains.
    YETI yard area.
    Download: Public Server Game 305 Final / Direct Link to this entry
    Public Server Game 304
    Game Date: 01.10.15 - 18.10.15
    Usual suspects: Sylf, dwarf, Jam35, Asgeir, Black, cha0tics, maraxus, Mazur, mari_kiri, Arveen, happy train sport, lol, glevans2, Purion (extend)
    Gametype: Cargo
    Trainlength: 3
    Mapsize: 512x512 Tropic (NewGRF+ Industries)
    Version used: r27387 #openttdcoop-GRF-Pack 8.0
    Remarks: This game featured a plan with 9 one-way rings, joined to next rings with hubs. A plan based on one-way rings allow us to build simpler hubs. Still, when the hubs are expanded from 2-line ML to 3-lines, and eventually to 4-lines, we see some impressive looking structures. We ended the game with nearly 2500 trains.
    BBH01, one of the hubs expanded to 4 lines in and out in all directions, surrounded by water. Very impressive expansion works.
    Download: Public Server Game 304 Final / Direct Link to this entry
    Public Server Game 303
    Game Date: 19.09.15 - 01.10.15
    Usual suspects: Jam35, dwarf, Maraxus, Mazur, Sylf, StarLite, lol, Plonka, glevans2, Sedontane, YellowMiner, Asgeir (extend)
    Gametype: FIRS 2 Cargo
    Trainlength: 5
    Mapsize: 512x512 Temperate
    Version used: r27387 #openttdcoop-GRF-Pack 8.0
    Remarks: The first outing for the FIRS2 industry newGRF. The game used transfer of supplies to primary drop stations so that primary trains with 2 dedicated supply wagons could drop them on their return journey. The many industry chains, 24 cargoes, with several sources and destinations make this game a little more complicated than the usual cargo game.
    Network Map.
