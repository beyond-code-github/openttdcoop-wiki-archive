    Vote: Public Server Game 6.2

    Reason: Two-tile-trains are just fun!

    Pros:

    1. a lot of interesting SL to 4-lane ML hubs <Doke>
    2. High traffic stations <Doke>

    Cons:

    1. Not all industries are connected <Doke>

    Note:

    “Load trains gradually” must be turned off to avoid jams at station entrances. Otherwise you get a 1200-trains-jam.

    The game doesn’t run with the newest nightlies, but with 0.5.3 it works fine.
