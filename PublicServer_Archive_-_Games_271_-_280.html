    Trainlength: TL9
    Mapsize: 512 x 256 Sub-Tropic

    Public Server Game 273
    Game Date: 19.1.2014-31.1.2014
    Usual suspects: V453000, Sylf, ryx, Hazzard, Jam35, Djanxy, Palen, Zxbiohazardzx, tyteen4a03, theholyduck, edi__, mek42, mfb, NCommander, Niradiel, sim-al2, Tray, Volatar, nicfer (extend)
    Gametype: Cargo Refit
    Trainlength: TL 5
    Mapsize: 512 x 512 Temperate
    Version used: r26264#openttdcoop-GRF-Pack 8.0
    Remarks: This is not your typical wet dream. We decided to play a refit game using the wetrail trains. It was a quick game, but we still managed to pack just under 1100 trains on the map. It is a watery map, and features several major constructs that are built directly on the water, using the canal cheats.

    Main stations and hubs are built around the water, like this side line hub.
